## 📖 Overview

**Neural Networks** is a collection of deep learning projects exploring various neural network architectures and their applications in computer vision and time-series forecasting.

The repository demonstrates practical implementations of Convolutional Neural Networks (CNNs) for image classification and memory-based neural networks such as LSTM for sequential data prediction.

These projects were developed to strengthen understanding of deep learning concepts, model training, and real-world AI applications.

---

## 🎯 Objectives

- Learn and implement neural network architectures.
- Build CNN models for image classification.
- Explore sequence learning using memory-based networks.
- Perform time-series forecasting.
- Understand model training, validation, and evaluation.
- Apply deep learning to practical datasets.

## ⚙ Installation

Clone the repository:

```bash

```

Navigate into the project:

```bash
cd Neural-Networks
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the desired project following its individual instructions.
